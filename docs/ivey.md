# Ivey mastery stages, mapped to the runbook

| Stage | Characteristic | Where the repo shows it |
|---|---|---|
| Novice | needs rules | `docs/runbook.md` |
| Advanced beginner | recognizes patterns | `mesh/specs_outside/README.md` shows the pattern of an INCOHERENT spec |
| Competent | plans | `pipe/autonomous_pipe.py`, eight stages |
| Proficient | sees situations as wholes | `mesh/specs_outside/` records why the format refuses |
| Expert | acts without explicit rules | `scripts/verify.sh` runs eleven stages with one command |

The repo is designed so a novice can use it (runbook) and an expert can
extend it (new specs, new models, new stages). No layer requires the
user to hold more context than its own file.
