# Changelog

## v0.1.0 — 2026-09-18

Packages:
- agentcy-core: hashing and canonical JSON primitives
- agentcy-cli: hash command
- agentcy-taxonomy: 16-level schema package with kinds, invariants, validator
- agentcy-hands: All Hands actors, archetypes, functions, work-assignment validator
- agentcy-ax: allocation matrix mapping 42 ontology categories to execution modes
- agentcy-agent-data: reference data engineering agent emitting scoped evidence

Compliance:
- 144 clauses enumerated across ISO 27001, NIST 800-53, SOC 2, NIST SSDF
- 16 level schemas generated
- 15 hand category lists generated
- 42 allocation categories emitted

Infrastructure:
- CI runs tests on Python 3.10/3.11/3.12
- SBOM generated on push to main
- Publish workflow ready for PyPI trusted publishing

What this repo does not claim:
- No certification from any standards body
- No legal recognition in any jurisdiction
- No completeness of the domain; scope is the declared bound only
