# Contributing

1. Fork the repository.
2. Create a branch `feat/<short-description>`.
3. Run `python -m pytest -q` before committing.
4. Commit with a signed-off-by line: `git commit -s -m "feat: ..."`.
5. Open a pull request. CI must pass. One approval required.

Commit subject format: `<type>: <description>` where type is one of
feat, fix, docs, ci, chore, refactor, test.
